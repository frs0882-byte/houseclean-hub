# HouseClean Hub | 原状回復・ハウスクリーニング業務・工程管理

原状回復工事・ハウスクリーニング・クロス工事の現場工程管理＆下請け発注書システム。
スマートフォン（PWA）およびPC対応。

## 主な機能
- **メイン予定カレンダー**: 案件全体の工期バー（登録日〜納期）、日別作業明細
- **業者予定（タイムライン）**: 下請け業者ごとの施工スケジュール＆複数日作業連動、稼働集計
- **工事依頼書PDF自動読込**: 金額・明細・工期・アクセスキーの自動抽出
- **下請け発注書自動作成**: 作業ごとの複数業者分割出力、A4一括印刷/PDF、LINE発注文面生成
- **LINE連携 & PWA対応**: スマホの共有メニューからPDFを直接読込、ホーム画面追加でアプリ化
